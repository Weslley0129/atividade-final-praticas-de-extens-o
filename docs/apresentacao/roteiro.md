## Dicas de gravação

- Se possível, grave a demonstração (slides 6 e 8) com a tela real do
  sistema rodando, não só a screenshot do slide — é mais convincente.
- Fale o roteiro com suas palavras; o texto de cada slide (nas notas do
  apresentador) é um guia, não para decorar.
- Grave um teste primeiro só de voz para calibrar o tempo antes da gravação
  final.
- Ferramentas simples para gravar tela + voz: OBS Studio (gratuito),
  gravador de tela nativo do Windows (Win+Alt+R com um app em foco), ou o
  Loom.
